# Campus Bites — Standalone College Canteen

This is a pure HTML, CSS, and JavaScript college-canteen app. It has no Node.js, npm, React, Vite, TypeScript, build step, or external JavaScript dependency.

## Open it

Double-click [index.html](index.html) or open it in any modern browser. No local web server is required.

## Included functionality

- Cafeteria, Timeless, and Nescafe, each with 30 menu items (90 total)
- Browse by canteen or cuisine, including price comparison across canteens
- Global dish/cuisine/canteen search, filters, and sorting
- Favorite dishes and recently viewed items, saved in browser local storage
- Daily specials, popular items, dark mode, responsive views, smooth CSS transitions
- Item detail, empty, loading, and missing-page states

## Project files

```text
index.html   Application shell
styles.css   Responsive visual design and animations
app.js       Menu data, navigation, filtering, state, and rendering
```
